<h1 align="center">💼 Job Portal Application</h1> <p align="center"> <b>Python | Tkinter | MySQL</b><br> A desktop-based application connecting <b>job seekers</b> and <b>employers</b> through an intuitive interface. </p>

🌟 Overview

This project is a Job Portal Desktop Application built using Python (Tkinter) for the GUI and MySQL for database management.
It provides a simple way for users to apply for jobs and for employers to manage their job postings — all from a single platform.

🔧 Features
👤 For Job Seekers

Register and log in

Search and view job listings

Apply for available jobs

View applied job history

🏢 For Employers

Employer registration and login

Post new jobs

Manage existing job posts

View and shortlist candidates

💡 Highlights

Fully functional Tkinter interface

Real-time data storage in MySQL

Role-based access (User/Employer)

Easy to customize and expand
